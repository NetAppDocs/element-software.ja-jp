= DeleteAllSupportBundles
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「 CreateSupportBundle'API メソッドで生成されたすべてのサポートバンドルを削除するには、「すべてのサポートバンドル」メソッドを使用します。



[[parameters]]
== パラメータ

このメソッドには入力パラメータはありません。



[[return-values]]
== 戻り値

このメソッドには戻り値はありません。



[[request-example]]
== 要求例

このメソッドの要求例を次に示します。

[listing]
----
{
   "method": "DeleteAllSupportBundles",
   "params": {}
  },
  "id": 1
}
----


[[response-example]]
== 応答例

このメソッドの応答例を次に示します。

[listing]
----
{
  "id" : 1,
  "result" : {}
 }
}
----
